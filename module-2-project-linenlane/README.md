# Northstar Module 2 Excel for Analysts

Module Project for Module 2 of Coding Temple's AI Data Analytics Foundations course at Northstar Data Group

## What is this

Analysis of synthetic dataset for LinenLane, a small online homegoods retailer.

Beatrix Holloway, VP of Marketing, wants to know what her sales, return, and marketing data are telling us about 2024 and how to adjust and move forward in 2025.

Included is a memo for VP Holloway sharing findings from the data, suggested import improvements to have cleaner data moving forward, and recommendations for both further analysis and action.
